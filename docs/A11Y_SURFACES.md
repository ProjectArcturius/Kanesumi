# 非主表面的无障碍发布

消费方是 Ceyboard 的候选窗与 LockScreen 的锁屏表面。旧接口、默认 feature 和映射规则不变。
每次表面树完成布局/绘制后，向已有 SnapshotSlot 发布同帧树，再刷新已有 AT-SPI bridge。
候选窗关闭到零尺寸时，已启用 a11y 的宿主发布仅根节点的视图，避免读屏保留旧候选。
多输出锁屏只发布主输出快照；副输出隐藏主界面的背板帧不得覆盖主输出快照。
未显式 enable_a11y 时，既有零尺寸早退与零发布开销保持不变；隐藏通知也不执行额外树帧。

## 表面释放入口

平台在候选窗零尺寸/引擎失活时直接释放 surface，不会再调用绘制入口。
为维护这条已有适配路径，App 新增默认空的 `ime_engine_popup_hidden()`；旧实现无需修改。
唯一生产调用方是 platform::refresh_im_popup 的实际释放分支，TreeHost 实现只撤下
无障碍视图的子节点并把焦点放回根，不清空应用模型或改动候选输入。重新出帧恢复真实树。
未开启 a11y 的默认实现无动作，不新增手写 UI 路径或图形初始化。
