## 三、本期实装（可验证）

1. **禁用项**：`MenuItem { enabled }` + `MenuItem::disabled()`；悬停不亮也不展开其子菜单、
   键盘导航与 Home/End 跳过、点击 / 回车不发动作且菜单不关、文字 / 图标 / 快捷键 / chevron 一起降透明度。
2. **勾选列**：`MENU_CHECK_GUTTER = 16`，仅在菜单存在可勾选项时预留；`glyph::check` 自绘折线（4 三角）。
3. **Home / End** 与 `→` 预选首个**可用**项。
4. **子菜单渲染去重**：`render_submenu` 改为委托 `render_panel`（旧实现是逐行复制的第二份排版，
   于是勾选列 / 禁用降透明度到不了子菜单 —— 截图里一眼能看出两级菜单长得不一样）。
5. 证据：`kanesumi-gallery/examples/menu_states_snapshot.rs`（一张图同时含禁用项、勾选项、级联、快捷键，2× 亲看）。

## 四、仍缺（下一批候选，按价值排）

1. **子菜单间距可配 + 入树**：现在固定 2pt；`MenuFlyoutSubItem` 的间距在真机上会随缩放取整，
   1.5×/2× 下是否出现 1px 缝未验。
2. **菜单条目级 AT 节点**：一个菜单仍是一个无障碍节点（无 `MenuItem` 逐个角色/名称/勾选态），
   读屏无法逐条枚举命令 —— 需先把条目拆成子节点（与「内容槽」同源问题）。
3. **长菜单滚动**：选项超过面板最大高度时没有滚动（WinUI 有 504pt 上限 + 滚动）。
4. **键盘焦点陷阱细节**：Tab 在菜单内是否应循环（WinUI：菜单内 Tab 不做焦点遍历）。
5. **真机手感**：以上全是无头像素与单元测试；菜单开合动画在 1×/1.5×/2× 的观感、以及
   ThinkPad/E495 上的实测仍为 NotRun。
