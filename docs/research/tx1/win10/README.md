# 真 Win10 截图（第一参照，待用户提供）

- 来源：用户舍友的 Win10 笔电（Win10 时代机型）。**必须 PNG 原图**（U 盘或微信「文件」发送；当图片发会被压成 JPEG，亚像素彩边被毁）。
- 内容：「设置」两三页（UWP + DirectWrite，最能代表 Win10 观感）、文件资源管理器（GDI）、开始菜单 / 磁贴。
- 每套截图记录：屏幕分辨率、缩放比例（100% / 150% / 200% 能切就各一套）；不运行 ClearType 调谐，保持原设置。
- 命名：`<场景>_<分辨率>_<缩放>.png`，例 `settings-network_1920x1080_150.png`。
